> [!NOTE]
> **Category Purpose:** Harness Anthropic's agentic command-line interface (`Claude Code`) to autonomously navigate codebases, edit files, run unit tests, and manage git workflows directly in your terminal.

---

## Planned Category Curriculum

1. **Claude Code Quickstart:** Installation (`npm i -g @anthropic-ai/claude-code`), authentication, and first commands.
2. **Terminal Interface & Commands:** Navigating the REPL, slash commands (`/compact`, `/clear`, `/cost`), and flags.
3. **Crafting the `CLAUDE.md` File:** Structuring repository rules, build commands, architecture guidelines, and code conventions.
4. **Codebase Navigation & Refactoring:** Searching large monorepos, tracing call stacks, and multi-file code modifications.
5. **Test-Driven Development Loops:** Running Pytest/Jest, inspecting failures, and letting Claude iterate until tests pass.
6. **Git & GitHub Automation:** Reviewing git diffs, writing conventional commits, creating branches, and drafting PRs.
7. **Context & Token Compaction:** Managing session context budgets to maintain high-speed coding performance.
8. **Safe Permissions & Tool Guards:** Configuring execution approvals, bash allow-lists, and read/write sandboxing.
