Congratulations on completing **Part B: AI Concepts for Working with AI Systems**! Before concluding your foundational training, review this self-assessment checklist across all eight architectural building blocks.

## Part B Competency Checklist

Use this checklist to confirm your mastery:

- [x] **[Compare small, medium, and large model tiers](module-06-types-of-models.md#model-tiers-small-medium-and-large)** and select the right model for speed, cost, and capability (Module 6).
- [x] **[Explain what a reasoning (thinking) model is](module-06-types-of-models.md#standard-models-vs-thinking-reasoning-models)** and when to enable extended thinking (Module 6).
- [x] **[Use the desk metaphor to explain context](module-07-context.md#the-desk-analogy)** and apply best practices to keep the desk clean and high-signal (Module 7).
- [x] **[Structure high-leverage prompts](module-08-prompting.md#the-four-parts-of-a-good-request)** using the four components: *Situation, Goal, Background, and Format* (Module 8).
- [x] **[Explain how persistent memory works](module-09-memory.md#short-term-vs-saved-persistent-memory)**, what should be stored (preferences, role), and what must never be stored (secrets, credentials) (Module 9).
- [x] **[Describe what a skill is](module-10-skills.md#what-a-skill-is)**, when to create one, and how skills keep the context desk uncluttered (Module 10).
- [x] **[Explain tools and the harness](module-11-tools-and-harness.md)**, understanding why the exact same model behaves differently across interfaces (Module 11).
- [x] **[Define an autonomous agent](module-12-agents.md)**, trace the *Think-Act-Check* loop, and describe how subagents handle large workloads in parallel (Module 12).
- [x] **[Give an agent a well-bounded goal](module-12-agents.md#giving-an-agent-a-good-goal)** with a clear finish line, explicit limits, and mandatory check-ins (Module 12).
- [x] **[Explain Allow, Ask, and Deny permissions](module-13-permissions-and-safety.md#the-three-permission-settings-allow-ask-deny)**, and demonstrate how to block sensitive files (such as `.env` files or HR directories) (Module 13).
- [x] **[Describe how all eight ideas integrate](worked-example.md)** in an end-to-end workplace scenario (like Asha's weekly status report assistant).
