> [!NOTE]
> This glossary provides plain-English explanations for the foundational concepts introduced in Part A. Each term links directly to its in-depth module explanation. For advanced system terms (such as *reasoning models, context desks, memory, skills, harnesses, and permissions*), see the [Part B Glossary](../part-b/glossary.md).

---

| Term | Plain-English Meaning | Primary Module Reference |
| :--- | :--- | :--- |
| <a id="ai-artificial-intelligence"></a>**AI (Artificial Intelligence)** | Computer programs that perform tasks that normally require human thinking (e.g., understanding language, spotting patterns, making suggestions). | [Module 1: What Is AI?](module-01-what-is-ai.md) |
| <a id="machine-learning"></a>**Machine Learning** | A way of building AI by showing a computer many examples, instead of manually writing rules for every situation. | [Module 1: How Terms Fit Together](module-01-what-is-ai.md#how-the-terms-fit-together) |
| <a id="model"></a>**Model** | The trained "brain" of an AI system. Claude is made up of a family of models. | [Module 1](module-01-what-is-ai.md#how-the-terms-fit-together) & [Part B, Module 6](../part-b/module-06-types-of-models.md#the-idea-in-brief) |
| <a id="llm-large-language-model"></a>**LLM (Large Language Model)** | A model trained on huge amounts of text so that it can understand, summarize, and generate human language. | [Module 2: What Is an LLM?](module-02-what-is-an-llm.md) |
| <a id="training"></a>**Training** | The process of teaching a model by exposing it to vast datasets so it learns patterns in words and ideas. | [Module 3: The Four Steps](module-03-how-llms-work.md#the-four-steps) |
| <a id="prompt"></a>**Prompt** | What you type to the AI: your instructions, questions, context, or reference text. | [Module 5](module-05-meet-claude.md#three-habits-for-good-results) & [Part B, Module 8](../part-b/module-08-prompting.md#the-4-part-request-framework) |
| <a id="token"></a>**Token** | A small piece of text (a single word, part of a word, or a punctuation mark) that the AI reads and writes. | [Module 2: Tokens](module-02-what-is-an-llm.md#tokens) |
| <a id="response-output"></a>**Response / Output** | The reply or finished text that the AI returns to you. | [Module 2: Why Answers Differ](module-02-what-is-an-llm.md#why-answers-can-differ-each-time) |
| <a id="context"></a>**Context** | Everything the AI can see at the exact moment it answers: your instructions, previous chat messages, attached files, and tool results. | [Part B, Module 7: Context](../part-b/module-07-context.md#the-desk-in-claude-code) |
| <a id="context-window"></a>**Context Window** | The limit on how much text the AI can hold in view at one time (like the surface area of a desk). | [Part B, Module 7: Desk Limit](../part-b/module-07-context.md#the-desk-has-a-size-limit-the-context-window) |
| <a id="hallucination"></a>**Hallucination** | When an AI states something factually false or made up, but presents it with complete confidence. | [Module 3](module-03-how-llms-work.md#3-hallucination) & [Module 4](module-04-strengths-limits-trust.md#where-it-needs-care) |
| <a id="knowledge-cutoff"></a>**Knowledge Cutoff** | The point in time after which the AI has not received training data; it does not know events past this date unless given tools or web search. | [Module 3](module-03-how-llms-work.md#1-it-has-a-knowledge-cutoff) & [Module 4](module-04-strengths-limits-trust.md#where-it-needs-care) |
| <a id="fine-tuning"></a>**Fine-Tuning** | Extra training after pretraining that guides the model to be a polite, helpful, and safe conversational assistant. | [Module 3: Step 2](module-03-how-llms-work.md#step-2-learning-to-be-helpful-fine-tuning-and-feedback) |
| <a id="agent"></a>**Agent** | An AI system that does not merely answer questions, but autonomously takes multi-step actions using tools to achieve a goal. | [Module 5: Chat vs. Agent](module-05-meet-claude.md#chat-vs-agent) & [Part B, Module 12](../part-b/module-12-agents.md#chat-vs-agent-the-shift-from-conversation-to-delegation) |
| <a id="tool"></a>**Tool** | An external capability the AI can invoke, such as running a calculation, reading a local file, or searching the web. | [Part B, Module 11: Tools](../part-b/module-11-tools-and-harness.md#tools-the-models-hands) |
| <a id="multimodal"></a>**Multimodal** | The ability of an AI model to work with formats beyond plain text, including photos, charts, diagrams, and PDF documents. | [Part B, Module 6: Multimodal](../part-b/module-06-types-of-models.md#multimodal-models-models-that-can-see) |
| <a id="api"></a>**API (Application Programming Interface)** | A technical bridge that allows software applications to communicate with Claude automatically. | [Module 5: Ways to Use Claude](module-05-meet-claude.md#ways-to-use-claude) |
