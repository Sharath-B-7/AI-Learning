> [!NOTE]
> **Category Purpose:** Create, prototype, and share standalone visual and technical assets—including interactive React applications, SVG illustrations, and Mermaid flowcharts—in a dedicated side-by-side workspace.

---

## Planned Category Curriculum

1. **Artifacts Fundamentals:** What triggers an Artifact, managing the split-screen view, and copying or downloading files.
2. **Building Interactive React Apps:** Prototyping live web calculators, dashboards, interactive models, and lightweight games.
3. **Generating Diagrams with Mermaid:** Creating architecture diagrams, flowcharts, sequence maps, and Gantt schedules.
4. **Vector Graphics with SVG:** Designing scalable SVG illustrations, company logos, icons, and infographics.
5. **Managing & Sharing Artifacts:** Inspecting underlying code, tracking version revisions, and publishing public links.
