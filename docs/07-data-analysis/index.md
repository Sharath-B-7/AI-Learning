## Planned Category Curriculum

1. **Analysis Tool Overview:** How the isolated code execution sandbox runs code safely and deterministically.
2. **Spreadsheet Cleaning & Wrangling:** Removing duplicates, handling nulls, normalizing dates, and restructuring tables.
3. **Business Intelligence & Metrics:** Calculating recurring revenue, churn rates, cohort retention, and margin analysis.
4. **Automated Chart Generation:** Plotting trends, distribution histograms, and exporting high-resolution charts.
5. **Statistical Problem Solving:** Hypothesis testing, A/B testing significance, and multi-variable regressions.
