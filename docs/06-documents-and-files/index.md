## Planned Category Curriculum

1. **Supported Formats & Limits:** File types, 30MB limits, token conversions, and batch uploading.
2. **PDF Deep Dive:** Visual page layout parsing vs text extraction for tables, footnotes, and diagrams.
3. **Multi-Document Synthesis:** Comparing conflicting contracts, merging multiple meeting transcripts, and gap analysis.
4. **Scanning Handwriting & Notes:** OCR for physical notebooks, whiteboard diagrams, and receipt audits.
