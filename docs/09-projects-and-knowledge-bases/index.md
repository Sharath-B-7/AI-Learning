## Planned Category Curriculum

1. **Projects Architecture:** How project memory, reference documents, and persistent custom instructions interact across chats.
2. **Setting Up Project Knowledge:** Curating reference files, managing token budgets, and preventing noise/contradictions.
3. **Crafting Project Instructions:** Writing standing guardrails, tone requirements, and industry-specific guidelines.
4. **Team Collaboration in Projects:** Sharing project workspaces across Team and Enterprise seats.
5. **Turnkey Project Templates:** Ready-to-use project setups for Product Management, Legal Review, Marketing, and Engineering.
