> **Category Purpose:** Master the official Anthropic prompt engineering framework—including XML tagging, role prompting, few-shot conditioning, and chain-of-thought—to elicit reliable, deterministic outputs.

---

## Planned Category Curriculum

1. **Prompt Engineering Fundamentals:** The core principles: clarity, directness, context separation, and unambiguous constraints.
2. **Anthropic XML Tagging Mastery:** Structuring inputs with `<instructions>`, `<context>`, `<documents>`, and `<output_format>`.
3. **Role Prompting & Personas:** Establishing domain authority without using superficial, flowery filler words.
4. **Few-Shot Prompting Exemplars:** Providing canonical examples to lock down formatting, tone, and edge-case handling.
5. **Chain-of-Thought Reasoning:** Instructing Claude to think step-by-step before answering to solve multi-stage problems.
6. **Debugging & Improving Prompts:** Eliminating sycophancy, preventing hallucinations, and fixing unnecessary refusals.
