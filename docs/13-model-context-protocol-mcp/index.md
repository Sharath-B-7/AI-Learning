## Planned Category Curriculum

1. **MCP Fundamentals:** Understanding the open standard—Hosts, Clients, Servers, stdio transports, and SSE networks.
2. **Configuring Claude Desktop MCP:** Step-by-step guide to editing `claude_desktop_config.json` with zero errors.
3. **Essential Prebuilt MCP Servers:** Connecting PostgreSQL, GitHub, Local Filesystem, Slack, and Google Drive.
4. **Building Your First MCP Server:** Writing custom tools, resources, and prompts in TypeScript or Python.
5. **Debugging MCP Connections:** Using the official MCP Inspector to test transports, tools, and error codes.
